# urudev.uy — Ingeniería de Software Enterprise

Plataforma oficial de **urudev.uy**. Desarrollamos software B2B a medida, sistemas de gestión y plataformas web de alta fiabilidad.

- **Ubicación:** Paysandú, Uruguay
- **Tecnologías:** React 19, TypeScript, Tailwind CSS, Vite

## Desarrollo Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
